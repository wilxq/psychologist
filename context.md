# Контекст проекта «Пространство»

## Общее

- Название: **Пространство**
- Тип: сайт-визитка (одностраничный, landing page)
- Психолог: **Анна Волкова**
- Специализация: тревожность, отношения, самооценка

## Дизайн

- Тёмная тема
- Без фотографий — работа цветом, типографикой и воздухом
- Цвета:
  - Тёмный фон — `#14120f`
  - Альтернативный фон — `#1c1a16`
  - Текст — `#e8e3d9`
  - Приглушённый текст — `#9a9488`
  - Акцент, кнопки — `#c17a5b`
- Шрифты:
  - Заголовки — **Cormorant**
  - Основной текст — **Inter**

## Структура страницы

Семь секций, идут по порядку:

1. `hero` — имя, короткий тезис, призыв к записи
2. `about` — о психологе, профессиональная позиция
3. `services` — форматы работы и стоимость
4. `approach` — как проходит консультация, принципы
5. `education` — образование, повышение квалификации, супервизии
6. `reviews` — отзывы клиентов (анонимно)
7. `contacts` — контактные данные и форма записи

## Интерактив

- Модальное окно записи (кнопки из hero и services)
- Форма обратной связи в секции `contacts`
- Слайдер отзывов
- Плавная прокрутка по якорям, мобильное меню

## Правила кода

- Без комментариев в коде
- Без inline-стилей
- Каждый селектор на новой строке
- CSS-переменные только в `:root`
